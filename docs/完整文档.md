# RESTful API 接口设计

## 一、接口规范

### 1.1 基础信息
- **Base URL**: `http://localhost:8080/api`
- **Content-Type**: `application/json`
- **字符编码**: `UTF-8`

### 1.2 认证方式
- 登录成功后服务端下发 JWT 令牌
- 请求头：`token: {JWT令牌}`
- 未登录时返回 401 状态码

### 1.3 统一响应格式
```json
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

| code | msg | 说明 |
|------|-----|------|
| 1 | success | 请求成功 |
| 0 | 具体错误信息 | 请求失败 |

## 四、待优化问题

### 🔴 类型冲突问题（建议修复）

**问题描述**: `stores/companion.ts` 与 `types/api.ts` 中的 `Companion` 类型字段不一致

| 文件 | 字段名 | 类型 | 含义 |
|------|--------|------|------|
| stores/companion.ts | `collected` | `number` | 收藏数量 |
| types/api.ts | `collected` | `boolean` | 是否已收藏 |

**建议修复方案**:
1. 在 `types/api.ts` 中的 `Companion` 接口添加 `collectedCount?: number` 字段
2. 修改 `stores/companion.ts` 使用新字段名 `collectedCount`

### 🟡 any 类型残留（可优化）

**问题描述**: `stores/message.ts` 第 69 行使用 `any` 类型

### 🟢 路径不一致（代码风格）

**问题描述**: `router/index.ts` 使用相对路径导入，其他文件使用别名路径
