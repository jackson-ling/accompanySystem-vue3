# 陪诊系统后端接口文档

## 1. 接口规范

### 1.1 协议与域名
- 协议：HTTP/HTTPS
- 基础路径：`/api`
- 字符编码：UTF-8
- 数据格式：JSON

### 1.2 认证方式
- 登录成功后服务端下发 JWT 令牌
- 请求头：`token: {JWT令牌}`
- 未登录时返回 401 状态码

**示例请求头：**
```
token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 1.3 统一响应格式
```json
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

| code | msg | 说明 |
|------|-----|------|
| 1 | success | 请求成功 |
| 0 | 具体错误信息 | 请求失败 |

### 1.4 分页参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 页码，默认1 |
| size | Integer | 否 | 每页数量，默认10 |

### 1.5 分页响应
```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "total": 100,
    "list": []
  }
}
```

## 2. 认证模块

### 2.1 用户注册
**接口地址：** `POST /auth/register`

**请求参数：**
```json
{
  "phone": "13800138000",
  "password": "123456",
  "nickname": "张三",
  "verifyCode": "123456"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 手机号 |
| password | String | 是 | 密码 |
| nickname | String | 是 | 昵称 |
| verifyCode | String | 是 | 验证码 |

**响应数据：**
```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": 1,
      "nickname": "张三",
      "avatar": "https://example.com/avatar.jpg",
      "phone": "13800138000",
      "balance": 0
    }
  }
}
```

### 2.2 用户登录
**接口地址：** `POST /auth/login`

**请求参数：**
```json
{
  "phone": "13800138000",
  "password": "123456"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 手机号 |
| password | String | 是 | 密码 |

**响应数据：** 同注册接口

### 2.3 用户退出
**接口地址：** `POST /auth/logout`

**请求头：** 需要认证

**响应数据：**
```json
{
  "code": 1,
  "msg": "success",
  "data": null
}
```

### 2.4 重置密码
**接口地址：** `POST /auth/reset-password`

**请求参数：**

### A. 数据模型

#### User（用户）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 用户ID |
| nickname | String | 昵称 |
| avatar | String | 头像URL |
| phone | String | 手机号 |
| password | String | 密码（加密） |
| balance | BigDecimal | 余额 |
| createTime | LocalDateTime | 创建时间 |

#### Patient（就诊人）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 就诊人ID |
| userId | Long | 用户ID |
| name | String | 姓名 |
| phone | String | 手机号 |
| address | String | 地址 |
| relationship | String | 关系 |
| isDefault | Boolean | 是否默认 |
| createTime | LocalDateTime | 创建时间 |

#### Service（服务）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 服务ID |
| name | String | 服务名称 |
| description | String | 服务描述 |
| price | BigDecimal | 价格 |
| type | String | 服务类型 |
| sales | Integer | 销量 |
| image | String | 图片URL |
| cover | String | 封面URL |
| duration | String | 服务时长 |

#### Companion（陪诊师）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 陪诊师ID |
| userId | Long | 用户ID |
| name | String | 姓名 |
| avatar | String | 头像URL |
| gender | String | 性别 |
| age | Integer | 年龄 |
| score | BigDecimal | 评分 |
| orders | Integer | 订单数 |
| certified | Boolean | 是否认证 |
| qualified | Boolean | 是否资质认证 |
| experience | String | 经验描述 |
| intro | String | 个人简介 |
| tags | String | 标签（JSON数组） |

#### Order（订单）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 订单ID |
| userId | Long | 用户ID |
| companionId | Long | 陪诊师ID |
| serviceId | Long | 服务ID |
| patientId | Long | 就诊人ID |
| hospital | String | 医院 |
| department | String | 科室 |
| appointmentTime | LocalDateTime | 预约时间 |
| pickupOption | String | 接送选项 |
| remarks | String | 备注 |
| amount | BigDecimal | 订单金额 |
| status | Integer | 订单状态 |
| createTime | LocalDateTime | 创建时间 |
| payTime | LocalDateTime | 支付时间 |
